# Cognitive Modeling-Final-Project
Project title: Binary Decision Modeling of LLM Behavior in High-Risk, Emotionally Charged Contexts
Team members: Michael Lam and Dillon Li

# Overview
In this project, we aim to develop statistical models that can analyze how large language models make decisions in high-stakes, real-life scenarios involving emotional and financial risk.

## Build and run

Assumes Python, the project dependencies, and a working CmdStan / CmdStanPy setup are already installed on your machine.

From the repository root:

```bash
cd "Decision-making Model"
python main.py
```

The script reads `data.csv` and `model.stan` in that folder and writes plots to `plots/`.
